# FAQ do aplicativo EV ChargeOps
Fonte: comportamento do projeto e cenário acadêmico, não manual do fabricante.
Como iniciar uma conversa? Entrar com a própria conta e usar o chat. Nova conversa cria outra sessão de memória.
Quem pode alterar um carregador? Uma conta admin ativa pode cadastrar ou editar no painel Gerenciar carregadores.
Posso mudar a tarifa? Somente no painel autorizado; o chat é consultivo e não realiza essa alteração.
Alterar a potência no painel controla o equipamento físico? Não. É apenas atualização do cadastro local.
O histórico permite filtrar por carregador, status e período. Os valores históricos permanecem preservados.
O aplicativo usa dados locais de demonstração; não representa monitoramento IoT de uma rede real.
