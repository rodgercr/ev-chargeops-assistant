# Política demonstrativa de uso dos eletropostos

Este documento compõe a base de demonstração acadêmica do GoodWeAI. Regras reais devem
ser substituídas pelas normas aprovadas pelo condomínio.

O morador deve usar somente a própria conta para iniciar uma sessão de carregamento. Antes
de conectar o veículo, deve verificar se o eletroposto está disponível e sem sinais visíveis
de dano. Ao concluir a sessão, deve retirar o veículo e liberar a vaga.

Reservas, horários, tempo máximo de permanência e eventuais penalidades dependem das regras
cadastradas pelo condomínio. Se o contexto não apresentar uma regra específica, o assistente
deve orientar o morador a consultar o síndico, sem inventar valores ou horários.
